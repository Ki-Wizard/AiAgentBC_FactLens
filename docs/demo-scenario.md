# Demo Scenario

## Demo Goal

틀린 AWS/AI 발표자료를 업로드했을 때 FactLens가 공식 근거와 충돌하는 claim을 찾아내는 장면을 보여줍니다.

## Demo Document

발표자료에는 다음 유형의 문장을 섞습니다.

- AWS 공식문서와 일치하는 문장
- AWS 공식문서와 충돌하는 문장
- 근거 문서에 없는 문장
- 맞는 내용을 과장한 문장

## Demo Flow

1. FactLens 화면에서 PDF를 업로드합니다.
2. 분석 진행 상태를 보여줍니다.
3. 결과 화면에서 claim별 색상 판정을 확인합니다.
4. 빨간 claim을 열어 어떤 공식 근거와 충돌하는지 보여줍니다.
5. 수정 제안 문장을 보여줍니다.

## Backup Plan

실시간 시연이 실패할 경우를 대비해 다음 자료를 준비합니다.

- 성공한 분석 결과 스크린샷
- 분석 결과 JSON
- 데모 PDF
- 아키텍처 다이어그램
