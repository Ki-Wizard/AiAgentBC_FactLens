## Common Rules

- 기본 브랜치: `main`
- 기능 브랜치 예시: `feature/frontend`, `feature/backend-api`, `feature/rag-bedrock`, `feature/demo-data`
- PR에는 변경 내용, 테스트 방법, 스크린샷 또는 실행 결과를 남깁니다.
