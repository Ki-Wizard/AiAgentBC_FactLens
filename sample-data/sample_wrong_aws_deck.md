# FactLens Demo Input

아래 문장은 FactLens MVP 시연을 위한 AWS/AI 발표자료 샘플입니다.

## Sample Claims

1. AWS Lambda 함수는 최대 5분까지만 실행할 수 있다.
2. Amazon S3는 객체 저장 서비스이며 정적 웹 사이트 호스팅에 사용할 수 있다.
3. Bedrock Knowledge Bases를 사용하면 RAG 애플리케이션에서 근거 문서를 검색할 수 있다.
4. Guardrails를 적용하면 모든 잘못된 답변을 100% 차단할 수 있다.
5. DynamoDB는 분석 결과와 job 상태를 저장하는 데 사용할 수 있다.
