# FactLens 데모용 AWS/AI 발표자료 샘플

이 문서는 FactLens 데모를 위해 의도적으로 맞는 문장, 틀린 문장, 근거 부족 문장, 과장 표현을 섞어 작성한 입력 자료다.

## AWS 서버리스와 생성형 AI 아키텍처

AWS Lambda 함수는 최대 5분까지만 실행할 수 있으므로 긴 배치 작업에는 절대 사용할 수 없다.

Amazon S3는 파일 시스템처럼 폴더 단위로 데이터를 저장하며, 객체마다 최대 1GB까지만 업로드할 수 있다.

Amazon DynamoDB는 관계형 데이터베이스이기 때문에 SQL JOIN을 기본 기능으로 제공한다.

Amazon Bedrock은 AWS에서 제공하는 생성형 AI 서비스이며, 여러 foundation model을 API로 사용할 수 있게 해준다.

Bedrock Knowledge Bases를 사용하면 외부 지식 소스를 검색해 RAG 기반 애플리케이션을 만들 수 있다.

EC2 Spot Instances는 중단될 가능성이 없어서 모든 실시간 운영 서비스에 항상 가장 안전한 선택이다.

RAG를 사용하면 LLM의 환각이 완전히 사라지므로 별도의 검증이나 출처 표시는 필요 없다.

우리 팀의 모든 AWS 문서는 항상 100% 정확하다.
